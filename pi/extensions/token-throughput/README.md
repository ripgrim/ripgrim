# @ripgrim/pi-token-throughput

## Token Throughput

Publishes live estimated and final provider-reported output throughput as `tok/s`.

## Install

From a clone of [`ripgrim/ripgrim`](https://github.com/ripgrim/ripgrim):

```bash
pi install ./pi/extensions/token-throughput
```

Run `/reload` in an existing Pi session after installation.
