# @ripgrim/pi-attachment-ux

## Attachment UX

Immediate clipboard feedback, atomic pasted-image chips, and clickable file paths.

## Install

From a clone of [`ripgrim/ripgrim`](https://github.com/ripgrim/ripgrim):

```bash
pi install ./pi/extensions/attachment-ux
```

Run `/reload` in an existing Pi session after installation.
